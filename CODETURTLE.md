# CodeTurtle review rules

Every changed part needs a review from the owner below. Add individual GitHub
usernames to assign more reviewers. Use `# codeturtle: all` to require every
listed owner; otherwise any listed owner can satisfy a rule.

```codeturtle
* @ATX24
```

Rules are loaded from the PR's target revision. Changing this file in a PR does
not weaken that PR's review requirements. New pushes create a fresh review.
